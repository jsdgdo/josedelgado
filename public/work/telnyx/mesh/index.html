Mesh Mobile

Brand: Telnyx
Role: Lead Product Designer
Timeline: 3 Months

Overview

At Telnyx, I helped rethink the mobile experience for the Mission Control Portal. Mesh Mobile is a tool that connects everyday work into one space. It gives teams AI tools—search, writing, note-taking—inside an all-in-one, flexible workspace. This project focused on ensuring technical parity while feeling native to mobile platforms.

The Challenge

The previous app felt slow and clunky. Users complained about the difficulty of finding documents on the go and the overwhelming navigation structure. The primary goal was to simplify the information architecture and introduce a new bottom navigation paradigm.

The Solution

We introduced a streamlined tab bar, improved the global search accessibility, and entirely revamped the editor experience to be touch-first. By removing nested menus, we increased daily active usage and significantly reduced time-to-task completion for core workflows.
